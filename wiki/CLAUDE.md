# wiki/ — Processing Scripts & Source Files

## Overview
This directory contains the Python processing pipeline and the source HTML/JS for the object wiki website. The `docs/` folder is a deploy copy of the static files here.

## Files

### convert_objects.py
- Converts OBJ meshes to GLB format using trimesh
- Looks for `.obj` files in `{name}/raw_mesh/{name}.obj` (skips "remeshed" variants)
- Uses `trimesh.load(obj_file, force='scene').export(glb_path, file_type='glb')` for lossless conversion
- Also generates `catalog.json` with metadata for each object
- `name_to_label()` converts snake_case IDs to Title Case display names

### generate_thumbnails.py
- Renders 256x256 thumbnails from OBJ meshes using pyrender
- Uses EGL backend (`PYOPENGL_PLATFORM=egl`) for headless rendering — no display needed
- Requires `PyOpenGL>=3.1.10` (3.1.0 crashes with Python 3.13 due to ctypes bug)
- Creates a single shared `OffscreenRenderer` for all objects (creating per-object causes EGL context issues)
- Camera: perspective at distance 2.0, slightly above center (y=0.3)
- Meshes are centered and normalized to unit scale before rendering
- Lighting: one directional light from camera position + one from above

### upload_to_hf.py
- Uploads the `output/objects/` folder to HuggingFace dataset repo `willi19/object_processing`
- Uses `HfApi().upload_folder()` for single-commit bulk upload
- Repo type is "dataset" (not "model")

### index.html (source)
- Main gallery page with search bar, category dropdown filter, thumbnail grid
- Fetches `catalog.json` at load, renders cards dynamically
- Thumbnails and GLBs loaded from HuggingFace: `https://huggingface.co/datasets/willi19/object_processing/resolve/main/`
- Cards link to `viewer.html?id={object_id}`
- Thumbnail `onerror` shows a placeholder glyph

### viewer.html (source)
- 3D viewer page using Babylon.js (loaded from CDN)
- Reads `?id=` query param to identify which object to show

### js/viewer.js
- Loads catalog.json, finds the object by ID, fetches GLB from HuggingFace
- **Important**: Fetches GLB as blob first, then passes blob URL to Babylon.js. Direct URL loading fails because Babylon.js doesn't handle HuggingFace's 302 redirects properly
- ArcRotateCamera with auto-fit to mesh bounding box (computes min/max across all mesh vertices)
- Lighting: HemisphericLight (intensity 0.8) + DirectionalLight (intensity 0.6)
- Dark background matching site theme (#0d1117)

### catalog.json
- Generated by `convert_objects.py`, lists all 102 objects
- Each entry: `{id, label, category, url, thumb}`
- `url` and `thumb` are relative paths (e.g. `objects/apple/mesh.glb`)
- Categories are currently all empty — can be filled in manually later

### output/ (gitignored)
- Build output directory containing `objects/{name}/mesh.glb` and `objects/{name}/thumb.png`
- These are uploaded to HuggingFace and not committed to git
